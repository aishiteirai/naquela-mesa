# F3 Pedido — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cliente monta o pedido no cardápio público (tamanho, meio a meio, adicionais, quantidade, observação), revisa na sacola, finaliza (delivery/retirada/mesa, pagamento offline), recebe a confirmação com botão "Enviar pedido no WhatsApp" e acompanha o status por link — com preço sempre recalculado no servidor.

**Architecture:** Novo módulo `orders` (schema de pedidos, contador por loja, precificação pura compartilhada servidor/navegador, serviço de cotação/criação/acompanhamento) e módulo `whatsapp` (mensagem e link `wa.me`). Na vitrine (`src/app/[slug]`), ilhas client: provedor do cardápio + sacola em `localStorage`, modal do item, barra da sacola, página `/[slug]/sacola` (checkout com Server Actions) e `/[slug]/pedido/[token]` (acompanhamento dinâmico). `storeId` do cliente vem **sempre do slug**; o carrinho envia só ids e quantidades.

**Tech Stack:** Next.js 16.4 (cacheComponents, Server Actions), React 19, Drizzle 0.45 + Postgres 17, Zod 4, Tailwind 4, Vitest 5, Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-13-naquela-mesa-mvp-design.md` (seções 5 "Pedidos", 6, 8, 9, 10; fase F3 da seção 12)

## Global Constraints

- Dinheiro sempre inteiro em centavos; exibição só via `formatBRL`.
- Textos de interface em português do Brasil.
- `src/app/` nunca acessa o banco; só chama módulos. Módulos só via `@/modules/<nome>` ou `@/modules/<nome>/client`; dentro do módulo `./`; `../` proibido em `src/` exceto `src/modules/*/schema.ts` → `../<mod>/schema`. Client components só importam `/client` de módulos (ou `import type`).
- **Preço é sempre calculado no servidor** a partir do cardápio atual (`getMenu`): o cliente envia apenas ids, quantidades, observações; o total exibido no navegador é só estimativa.
- No fluxo do cliente não há sessão: a loja vem do `slug` da URL; todo id recebido é conferido contra o cardápio **daquela** loja.
- Server Actions do cliente são públicas: validar tudo com Zod; campo honeypot `website` preenchido → recusar.
- Itens do pedido guardam **cópia** de nomes e preços (snapshot).
- Página de acompanhamento mostra só primeiro nome, status, itens e totais — **sem telefone nem endereço**. A mensagem completa do WhatsApp (com endereço/telefone) só aparece na tela de confirmação logo após o pedido (deliberado: a spec §6 põe o botão na página de acompanhamento, mas a §9 exige que ela mostre o mínimo).
- Número do pedido sequencial por loja via tabela `order_counters` (deliberado: substitui `stores.order_seq`, que fica sem uso, para o módulo `orders` não escrever na tabela de `stores`). Exibição: `#0001`.
- `public_token` com ≥ 128 bits (32 bytes aleatórios em base64url).
- Next 16 `cacheComponents`: leituras dinâmicas dentro de `<Suspense>`; página de acompanhamento sem cache (`connection()`).
- Postgres local porta 5434; worktree F3 usa banco `naquela_mesa_f2` e porta 3001.
- Commits terminam com linha em branco + trailer `Co-Authored-By:` do modelo que escreveu.
- Branch `f3-pedido`.

## Review Focus

1. Cliente envia id de produto/tamanho/opção de **outra loja** ou inativo/esgotado → recusado (`ITEM_UNAVAILABLE`/`INVALID_OPTIONS`), nada gravado. Teste: Task 4.
2. Total enviado pelo navegador diferente do recalculado (preço mudou entre revisar e confirmar) → `PRICE_CHANGED` com o novo total; nenhum pedido gravado. Teste: Task 4.
3. Clique duplo / reenvio com a mesma `idempotencyKey` → um único pedido, mesmo número. 10 pedidos em paralelo → números 1..10 sem repetir. Teste: Task 4.
4. Meio a meio: preço pelo sabor mais caro (ou média arredondada para cima), sabores de categorias diferentes ou que não permitem meio a meio → recusado; grupo de adicionais com mínimo obrigatório não atendido → recusado. Teste: Task 3.
5. Página de acompanhamento de outro pedido / token inválido → "Pedido não encontrado"; HTML da página não contém telefone nem rua do cliente. Teste: Task 9 (E2E).

```ts
import { sql } from "drizzle-orm";
import { check, index, integer, jsonb, pgTable, text, timestamp, uniqueIndex, uuid } from "drizzle-orm/pg-core";
import { user } from "../auth/schema";
import { stores } from "../stores/schema";
import { FULFILLMENTS, ORDER_CHANNELS, ORDER_STATUSES, PAYMENT_METHODS, type OrderAddress } from "./types";

/** Último número de pedido emitido por loja (incremento atômico via upsert). */
export const orderCounters = pgTable("order_counters", {
  storeId: uuid("store_id")
    .primaryKey()
    .references(() => stores.id, { onDelete: "cascade" }),
  lastNumber: integer("last_number").notNull().default(0),
});

export const orders = pgTable(
  "orders",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    storeId: uuid("store_id")
      .notNull()
      .references(() => stores.id, { onDelete: "cascade" }),
    number: integer("number").notNull(),
    publicToken: text("public_token").notNull().unique(),
    idempotencyKey: uuid("idempotency_key").notNull(),
    channel: text("channel", { enum: ORDER_CHANNELS }).notNull(),
    status: text("status", { enum: ORDER_STATUSES }).notNull().default("received"),
    fulfillment: text("fulfillment", { enum: FULFILLMENTS }).notNull(),
    customerName: text("customer_name").notNull(),
    customerPhone: text("customer_phone").notNull(),
    address: jsonb("address").$type<OrderAddress>(),
    tableLabel: text("table_label"),
    paymentMethod: text("payment_method", { enum: PAYMENT_METHODS }).notNull(),
    changeForCents: integer("change_for_cents"),
    notes: text("notes"),
    cancelReason: text("cancel_reason"),
    subtotalCents: integer("subtotal_cents").notNull(),
    deliveryFeeCents: integer("delivery_fee_cents").notNull(),
    discountCents: integer("discount_cents").notNull().default(0),
    totalCents: integer("total_cents").notNull(),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
  },
  (t) => [
    index("orders_store_created_at_idx").on(t.storeId, t.createdAt),
    uniqueIndex("orders_store_number_idx").on(t.storeId, t.number),
    uniqueIndex("orders_store_idempotency_idx").on(t.storeId, t.idempotencyKey),
    check(
      "orders_amounts_check",
      sql`${t.subtotalCents} >= 0 and ${t.deliveryFeeCents} >= 0 and ${t.discountCents} >= 0 and ${t.totalCents} >= 0`,
    ),
  ],
);

export const orderItems = pgTable(
  "order_items",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    orderId: uuid("order_id")
      .notNull()
      .references(() => orders.id, { onDelete: "cascade" }),
    productName: text("product_name").notNull(),
    sizeName: text("size_name"),
    flavors: jsonb("flavors").$type<string[]>().notNull().default(sql`'[]'::jsonb`),
    quantity: integer("quantity").notNull(),
    unitPriceCents: integer("unit_price_cents").notNull(),
    totalCents: integer("total_cents").notNull(),
    notes: text("notes"),
    position: integer("position").notNull().default(0),
  },
  (t) => [index("order_items_order_id_idx").on(t.orderId)],
);

export const orderItemOptions = pgTable(
  "order_item_options",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    orderItemId: uuid("order_item_id")
      .notNull()
      .references(() => orderItems.id, { onDelete: "cascade" }),
    groupName: text("group_name").notNull(),
    optionName: text("option_name").notNull(),
    priceCents: integer("price_cents").notNull(),
  },
  (t) => [index("order_item_options_item_id_idx").on(t.orderItemId)],
);

export const orderStatusEvents = pgTable(
  "order_status_events",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    orderId: uuid("order_id")
      .notNull()
      .references(() => orders.id, { onDelete: "cascade" }),
    status: text("status", { enum: ORDER_STATUSES }).notNull(),
    at: timestamp("at", { withTimezone: true }).notNull().defaultNow(),
    byUserId: text("by_user_id").references(() => user.id, { onDelete: "set null" }),
  },
  (t) => [index("order_status_events_order_id_idx").on(t.orderId)],
);
```

```ts
import type { Menu, MenuCategory, MenuOptionGroup, MenuProduct } from "@/modules/catalog";
import { DomainError } from "@/shared/errors";

export type CartItemInput =
  | { kind: "simple"; productId: string; optionIds: string[]; quantity: number; notes: string | null }
  | { kind: "sized"; sizeId: string; flavorIds: string[]; optionIds: string[]; quantity: number; notes: string | null };

export type PricedOption = { groupName: string; optionName: string; priceCents: number };

export type PricedLine = {
  productName: string;
  sizeName: string | null;
  flavors: string[];
  options: PricedOption[];
  quantity: number;
  unitPriceCents: number;
  totalCents: number;
  notes: string | null;
};

export type PricingContext = {
  menu: Menu;
  halfPriceRule: "highest" | "average";
  halfAndHalfEnabled: boolean;
  addonsEnabled: boolean;
};

export const MAX_ITEM_QUANTITY = 50;

function unavailable(itemIndex: number, name: string): DomainError {
  return new DomainError("ITEM_UNAVAILABLE", { itemIndex, name });
}

function invalidOptions(itemIndex: number, reason: string): DomainError {
  return new DomainError("INVALID_OPTIONS", { itemIndex, reason });
}

function findProduct(menu: Menu, productId: string): MenuProduct | null {
  for (const category of menu.categories) {
    const product = category.products.find((item) => item.id === productId);
    if (product) return product;
  }
  return null;
}

function findSize(menu: Menu, sizeId: string): { size: MenuCategory["sizes"][number]; category: MenuCategory } | null {
  for (const category of menu.categories) {
    const size = category.sizes.find((item) => item.id === sizeId);
    if (size) return { size, category };
  }
  return null;
}

function priceOptions(ctx: PricingContext, itemIndex: number, groupIds: string[], optionIds: string[]): PricedOption[] {
  if (!ctx.addonsEnabled) {
    if (optionIds.length > 0) throw invalidOptions(itemIndex, "adicionais indisponíveis");
    return [];
  }
  if (new Set(optionIds).size !== optionIds.length) throw invalidOptions(itemIndex, "adicional repetido");

  const remaining = new Set(optionIds);
  const priced: PricedOption[] = [];
  const groups = groupIds
    .map((groupId) => ctx.menu.optionGroups.find((group) => group.id === groupId))
    .filter((group): group is MenuOptionGroup => group !== undefined);

  for (const group of groups) {
    const chosen = group.options.filter((option) => remaining.has(option.id));
    for (const option of chosen) remaining.delete(option.id);

    if (chosen.length < group.minSelect) throw invalidOptions(itemIndex, `escolha ao menos ${group.minSelect} em ${group.name}`);
    if (chosen.length > group.maxSelect) throw invalidOptions(itemIndex, `escolha no máximo ${group.maxSelect} em ${group.name}`);

    for (const option of chosen) {
      if (!option.available) throw unavailable(itemIndex, option.name);
      priced.push({ groupName: group.name, optionName: option.name, priceCents: option.priceCents });
    }
  }

  if (remaining.size > 0) throw invalidOptions(itemIndex, "adicional não pertence a este item");
  return priced;
}

export function priceItem(ctx: PricingContext, item: CartItemInput, itemIndex: number): PricedLine {
  if (!Number.isInteger(item.quantity) || item.quantity < 1 || item.quantity > MAX_ITEM_QUANTITY) {
    throw new DomainError("VALIDATION", { issues: [{ path: `items.${itemIndex}.quantity`, message: "quantidade inválida" }] });
  }

  let baseCents: number;
  let productName: string;
  let sizeName: string | null = null;
  let flavors: string[] = [];
  let groupIds: string[];

  if (item.kind === "simple") {
    const product = findProduct(ctx.menu, item.productId);
    if (!product) throw unavailable(itemIndex, "item");
    if (product.priceCents === null || product.sizePrices.length > 0) throw invalidOptions(itemIndex, "escolha um tamanho");
    if (!product.available) throw unavailable(itemIndex, product.name);
    baseCents = product.priceCents;
    productName = product.name;
    groupIds = product.optionGroupIds;
  } else {
    const found = findSize(ctx.menu, item.sizeId);
    if (!found) throw unavailable(itemIndex, "tamanho");
    const { size, category } = found;
    const ids = item.flavorIds;
    if (ids.length < 1 || ids.length > size.maxFlavors || new Set(ids).size !== ids.length) {
      throw invalidOptions(itemIndex, `escolha de 1 a ${size.maxFlavors} sabores`);
    }

    const flavorProducts: MenuProduct[] = [];
    for (const flavorId of ids) {
      const product = category.products.find((candidate) => candidate.id === flavorId);
      if (!product) throw unavailable(itemIndex, "sabor");
      flavorProducts.push(product);
    }
    if (flavorProducts.length > 1 && (!ctx.halfAndHalfEnabled || flavorProducts.some((product) => !product.allowsHalf))) {
      throw invalidOptions(itemIndex, "meio a meio indisponível para estes sabores");
    }

    const prices = flavorProducts.map((product) => {
      if (!product.available) throw unavailable(itemIndex, product.name);
      const price = product.sizePrices.find((candidate) => candidate.sizeId === size.id);
      if (!price) throw unavailable(itemIndex, `${product.name} (${size.name})`);
      return price.priceCents;
    });

    baseCents =
      ctx.halfPriceRule === "highest"
        ? Math.max(...prices)
        : Math.ceil(prices.reduce((sum, price) => sum + price, 0) / prices.length);
    productName = flavorProducts.map((product) => product.name).join(" / ");
    sizeName = size.name;
    flavors = flavorProducts.map((product) => product.name);
    groupIds = [...new Set(flavorProducts.flatMap((product) => product.optionGroupIds))];
  }

  const options = priceOptions(ctx, itemIndex, groupIds, item.optionIds);
  const unitPriceCents = baseCents + options.reduce((sum, option) => sum + option.priceCents, 0);

  return {
    productName,
    sizeName,
    flavors,
    options,
    quantity: item.quantity,
    unitPriceCents,
    totalCents: unitPriceCents * item.quantity,
    notes: item.notes?.trim() || null,
  };
}

export function priceCart(ctx: PricingContext, items: CartItemInput[]): { lines: PricedLine[]; subtotalCents: number } {
  if (items.length === 0) {
    throw new DomainError("VALIDATION", { issues: [{ path: "items", message: "sua sacola está vazia" }] });
  }
  const lines = items.map((item, index) => priceItem(ctx, item, index));
  return { lines, subtotalCents: lines.reduce((sum, line) => sum + line.totalCents, 0) };
}

export function describeLine(line: Pick<PricedLine, "productName" | "sizeName" | "flavors">): string {
  if (line.sizeName === null) return line.productName;
  if (line.flavors.length > 1) return `${line.sizeName} — ${line.flavors.map((flavor) => `½ ${flavor}`).join(" + ")}`;
  return `${line.flavors[0] ?? line.productName} (${line.sizeName})`;
}
```

```ts
/** Normaliza telefone para E.164. Sem "+": assume Brasil (DDD + número). */
export function normalizeBrazilPhone(input: string): string | null {
  const digits = input.replace(/\D/g, "");
  if (input.trim().startsWith("+")) return digits.length >= 8 && digits.length <= 15 ? `+${digits}` : null;
  if (digits.length === 10 || digits.length === 11) return `+55${digits}`;
  if ((digits.length === 12 || digits.length === 13) && digits.startsWith("55")) return `+${digits}`;
  return null;
}
```

```ts
function parseCheckout(input: unknown): ParsedCheckout {

async function loadStore(slug: string): Promise<Store> {

function normalizeNeighborhood(value: string): string {
  return value.trim().toLocaleLowerCase("pt-BR");

function assertOperation(store: Store, input: ParsedCheckout, now: Date): void {
  const fulfillmentEnabled: Record<Fulfillment, boolean> = {
    delivery: store.features.delivery,
    pickup: store.features.pickup,
    dine_in: store.features.dineIn,
  };
  if (!fulfillmentEnabled[input.fulfillment]) throw new DomainError("FULFILLMENT_DISABLED", { fulfillment: input.fulfillment });

  const paymentEnabled: Record<PaymentMethod, boolean> = {
    cash: store.paymentMethods.cash,
    card_on_delivery: store.paymentMethods.cardOnDelivery,
    pix: store.paymentMethods.pixKey !== null,
  };
  if (!paymentEnabled[input.payment.method]) throw new DomainError("PAYMENT_DISABLED", { method: input.payment.method });

  const status = getOpenStatus({ hours: store.hours, manualStatus: store.manualStatus, timeZone: store.timezone, now });
  if (!status.isOpen) throw new DomainError("STORE_CLOSED", { message: formatOpenStatus(status) });
}

function deliveryFee(store: Store, zones: DeliveryZone[], input: ParsedCheckout): number {
  if (input.fulfillment !== "delivery" || !input.address) return 0;
  const rule = store.rules.deliveryFee;
  if (rule.strategy === "fixed") return rule.fixedCents;

  const wanted = normalizeNeighborhood(input.address.neighborhood);
  const zone = zones.find((candidate) => normalizeNeighborhood(candidate.neighborhood) === wanted);
  if (!zone) throw new DomainError("ZONE_NOT_SERVED", { neighborhood: input.address.neighborhood });
  return zone.feeCents;
}

function computeQuote(store: Store, menu: Menu, zones: DeliveryZone[], input: ParsedCheckout, now: Date): OrderQuote {
  assertOperation(store, input, now);
  const { lines, subtotalCents } = priceCart(
    {
      menu,
      halfPriceRule: store.rules.halfPriceRule,
      halfAndHalfEnabled: store.features.halfAndHalf,
      addonsEnabled: store.features.addons,
    },
    input.items,
  );
  if (subtotalCents < store.rules.minOrderCents) {
    throw new DomainError("BELOW_MIN_ORDER", { minOrderCents: store.rules.minOrderCents });
  }

  const deliveryFeeCents = deliveryFee(store, zones, input);
  const totalCents = subtotalCents + deliveryFeeCents;
  if (totalCents > MAX_ORDER_CENTS) throw validation("items", "pedido acima do limite");
  if (input.payment.method === "cash" && input.payment.changeForCents !== null && input.payment.changeForCents < totalCents) {
    throw validation("payment.changeForCents", "o troco deve ser maior que o total");
  }
  return { lines, subtotalCents, deliveryFeeCents, totalCents };
}

async function quoteFor(store: Store, input: ParsedCheckout, now: Date): Promise<OrderQuote> {
  const [menu, zones] = await Promise.all([getMenu(store.id), getDeliveryZones(store.id)]);

}

export async function createOrder(
  slug: string,
  rawInput: unknown,
  channel: OrderChannel = "web",
  now: Date = new Date(),
): Promise<PlacedOrder> {
  const input = parseCheckout(rawInput);
  if (input.expectedTotalCents === null) throw validation("expectedTotalCents", "revise o pedido antes de confirmar");
  const phone = normalizeBrazilPhone(input.customer.phone);
  if (!phone) throw validation("customer.phone", "telefone inválido (use DDD + número)");

  const store = await loadStore(slug);
  const existing = await findByIdempotency(store.id, input.idempotencyKey);
  if (existing) return loadPlacedOrder(existing);

  const quote = await quoteFor(store, input, now);
  if (quote.totalCents !== input.expectedTotalCents) throw new DomainError("PRICE_CHANGED", { quote });

  try {
    const orderId = await db.transaction(async (tx) => {
      // Upsert com incremento: a linha do contador serializa pedidos concorrentes da mesma loja.
      const [counter] = await tx
        .insert(orderCounters)
        .values({ storeId: store.id, lastNumber: 1 })
        .onConflictDoUpdate({ target: orderCounters.storeId, set: { lastNumber: sql`${orderCounters.lastNumber} + 1` } })
        .returning({ lastNumber: orderCounters.lastNumber });

      const [order] = await tx
        .insert(orders)
        .values({
          storeId: store.id,
          number: counter!.lastNumber,
          publicToken: randomBytes(32).toString("base64url"),
          idempotencyKey: input.idempotencyKey,
          channel,
          fulfillment: input.fulfillment,
          customerName: input.customer.name,
          customerPhone: phone,
          address: input.fulfillment === "delivery" ? input.address : null,
          tableLabel: input.fulfillment === "dine_in" ? input.tableLabel : null,
          paymentMethod: input.payment.method,
          changeForCents: input.payment.method === "cash" ? input.payment.changeForCents : null,
          notes: input.notes,
          subtotalCents: quote.subtotalCents,
          deliveryFeeCents: quote.deliveryFeeCents,
          totalCents: quote.totalCents,
        })
        .returning({ id: orders.id });

      for (const [position, line] of quote.lines.entries()) {
        const [item] = await tx
          .insert(orderItems)
          .values({
            orderId: order!.id,
            productName: line.productName,
            sizeName: line.sizeName,
            flavors: line.flavors,
            quantity: line.quantity,
            unitPriceCents: line.unitPriceCents,
            totalCents: line.totalCents,
            notes: line.notes,
            position,
          })
          .returning({ id: orderItems.id });
        if (line.options.length > 0) {
          await tx.insert(orderItemOptions).values(line.options.map((option) => ({ orderItemId: item!.id, ...option })));
        }
      }

      await tx.insert(orderStatusEvents).values({ orderId: order!.id, status: "received" });
      return order!.id;
    });
    return loadPlacedOrder(orderId);
  } catch (error) {
    // Corrida de clique duplo: o outro request gravou primeiro com a mesma chave.
    if (isUniqueViolation(error)) {
      const raced = await findByIdempotency(store.id, input.idempotencyKey);
      if (raced) return loadPlacedOrder(raced);
    }
    throw error;
  }
}

export async function getOrderTracking(publicToken: string): Promise<OrderTracking | null> {
  if (!PUBLIC_TOKEN_PATTERN.test(publicToken)) return null;
  const [order] = await db.select().from(orders).where(eq(orders.publicToken, publicToken)).limit(1);
  if (!order) return null;
  const store = await getStoreById(order.storeId);
  if (!store) return null;
  const lines = await loadLines(order.id);

  return {

    status: order.status,
    fulfillment: order.fulfillment,
    customerFirstName: order.customerName.split(/\s+/)[0] ?? order.customerName,

    items: lines.map((line) => ({
      description: describeLine(line),
      quantity: line.quantity,
      totalCents: line.totalCents,
      options: line.options.map((option) => `${option.groupName}: ${option.optionName}`),
    })),
    subtotalCents: order.subtotalCents,
    deliveryFeeCents: order.deliveryFeeCents,
    totalCents: order.totalCents,
    paymentMethod: order.paymentMethod,
    store: { slug: store.slug, name: store.name, whatsappPhone: store.whatsappPhone, timezone: store.timezone },
  };
}
```

```ts
import { describeLine, formatOrderNumber, FULFILLMENT_LABELS, PAYMENT_LABELS, type PlacedOrder } from "@/modules/orders";
import { formatBRL } from "@/shared/money";

export function waMeLink(phoneE164: string, text: string): string {
  return `https://wa.me/${phoneE164.replace(/\D/g, "")}?text=${encodeURIComponent(text)}`;
}

export function buildOrderMessage(order: PlacedOrder, trackingUrl: string): string {
  const out: string[] = [
    `*Pedido ${formatOrderNumber(order.number)}* — ${order.store.name}`,
    FULFILLMENT_LABELS[order.fulfillment],
    `Cliente: ${order.customerName} (${order.customerPhone})`,
    "",
  ];

  for (const line of order.lines) {
    out.push(`${line.quantity}x ${describeLine(line)} — ${formatBRL(line.totalCents)}`);
    for (const option of line.options) out.push(`   + ${option.groupName}: ${option.optionName}`);
    if (line.notes) out.push(`   Obs.: ${line.notes}`);
  }

  out.push("", `Subtotal: ${formatBRL(order.subtotalCents)}`);
  if (order.fulfillment === "delivery") out.push(`Entrega: ${formatBRL(order.deliveryFeeCents)}`);
  out.push(`*Total: ${formatBRL(order.totalCents)}*`);
  const change = order.changeForCents ? ` (troco para ${formatBRL(order.changeForCents)})` : "";
  out.push(`Pagamento: ${PAYMENT_LABELS[order.paymentMethod]}${change}`);

  const details: string[] = [];
  if (order.address) {
    const complement = order.address.complement ? ` - ${order.address.complement}` : "";
    details.push(`Endereço: ${order.address.street}, ${order.address.number}${complement} — ${order.address.neighborhood}`);
    if (order.address.reference) details.push(`Referência: ${order.address.reference}`);
  }
  if (order.tableLabel) details.push(`Mesa: ${order.tableLabel}`);
  if (order.notes) details.push(`Obs. do pedido: ${order.notes}`);
  if (details.length > 0) out.push("", ...details);

  out.push("", `Acompanhe: ${trackingUrl}`);
  return out.join("\n");
}

export function buildContactMessage(orderNumber: number, trackingUrl: string): string {
  return `Olá! Sobre o meu pedido ${formatOrderNumber(orderNumber)}: ${trackingUrl}`;
}
```

```tsx
"use client";

import { createContext, useCallback, useContext, useEffect, useMemo, useState, type ReactNode } from "react";
import { MAX_ITEM_QUANTITY, type CartItemInput } from "@/modules/orders/client";

export type CartLine = { key: string; input: CartItemInput; label: string; unitPriceCents: number };

type CartValue = {
  lines: CartLine[];
  ready: boolean;
  count: number;
  estimatedSubtotalCents: number;
  add(line: Omit<CartLine, "key">): void;
  setQuantity(key: string, quantity: number): void;
  remove(key: string): void;
  clear(): void;
};

const CartContext = createContext<CartValue | null>(null);

function storageKey(slug: string): string {
  return `naquela-mesa:sacola:${slug}`;
}

function readStored(slug: string): CartLine[] {
  try {
    const parsed: unknown = JSON.parse(window.localStorage.getItem(storageKey(slug)) ?? "[]");
    return Array.isArray(parsed) ? (parsed as CartLine[]) : [];
  } catch {
    return [];
  }
}

export function CartProvider({ slug, children }: { slug: string; children: ReactNode }) {
  const [lines, setLines] = useState<CartLine[]>([]);
  const [ready, setReady] = useState(false);

  useEffect(() => {
    setLines(readStored(slug));
    setReady(true);
  }, [slug]);

  useEffect(() => {
    if (!ready) return;
    try {
      window.localStorage.setItem(storageKey(slug), JSON.stringify(lines));
    } catch {
      // Armazenamento indisponível (modo privado): a sacola vale só nesta página.
    }
  }, [lines, ready, slug]);

  const add = useCallback((line: Omit<CartLine, "key">) => {
    setLines((current) => [...current, { ...line, key: crypto.randomUUID() }]);
  }, []);

  const setQuantity = useCallback((key: string, quantity: number) => {
    setLines((current) =>
      quantity < 1
        ? current.filter((line) => line.key !== key)
        : current.map((line) =>
            line.key === key ? { ...line, input: { ...line.input, quantity: Math.min(quantity, MAX_ITEM_QUANTITY) } } : line,
          ),
    );
  }, []);

  const remove = useCallback((key: string) => setLines((current) => current.filter((line) => line.key !== key)), []);
  const clear = useCallback(() => setLines([]), []);

  const value = useMemo<CartValue>(
    () => ({
      lines,
      ready,
      count: lines.reduce((sum, line) => sum + line.input.quantity, 0),
      estimatedSubtotalCents: lines.reduce((sum, line) => sum + line.unitPriceCents * line.input.quantity, 0),
      add,
      setQuantity,
      remove,
      clear,
    }),
    [lines, ready, add, setQuantity, remove, clear],
  );

  return <CartContext value={value}>{children}</CartContext>;
}

export function useCart(): CartValue {
  const value = useContext(CartContext);
  if (!value) throw new Error("CartProvider ausente");
  return value;
}
```

```ts
import type { OrderQuote } from "@/modules/orders";
import type { DomainError } from "@/shared/errors";
import { formatBRL } from "@/shared/money";

export type CheckoutError = { code: string; message: string; fieldErrors: Record<string, string>; quote?: OrderQuote };

function plain(code: string, message: string): CheckoutError {
  return { code, message, fieldErrors: {} };
}

export function toCheckoutError(error: DomainError): CheckoutError {
  const details = error.details;
  switch (error.code) {
    case "STORE_CLOSED":
      return plain(error.code, `A loja está fechada agora. ${String(details.message ?? "")}`.trim());
    case "ITEM_UNAVAILABLE":
      return plain(error.code, `${String(details.name ?? "Um item")} não está disponível. Remova da sacola e tente de novo.`);
    case "INVALID_OPTIONS":
      return plain(error.code, `Revise o item ${Number(details.itemIndex ?? 0) + 1} da sacola: ${String(details.reason ?? "opções inválidas")}.`);
    case "BELOW_MIN_ORDER":
      return plain(error.code, `Pedido mínimo de ${formatBRL(Number(details.minOrderCents ?? 0))} (sem a entrega).`);
    case "ZONE_NOT_SERVED":
      return plain(error.code, "Ainda não entregamos nesse bairro. Que tal retirar no balcão?");
    case "FULFILLMENT_DISABLED":
      return plain(error.code, "Esse tipo de pedido não está disponível agora. Escolha outra opção.");
    case "PAYMENT_DISABLED":
      return plain(error.code, "Essa forma de pagamento não está disponível. Escolha outra.");
    case "PRICE_CHANGED":
      return {
        ...plain(error.code, "Os preços mudaram desde a revisão. Confira o novo total e confirme de novo."),
        quote: details.quote as OrderQuote,
      };
    case "NOT_FOUND":
      return plain(error.code, "Loja não encontrada.");
    case "VALIDATION": {
      const issues = (details.issues ?? []) as { path: string; message: string }[];
      return {
        code: error.code,
        message: "Confira os campos destacados.",
        fieldErrors: Object.fromEntries(issues.map((issue) => [issue.path || "_", issue.message])),
      };
    }
    default:
      return plain(error.code, "Não foi possível enviar o pedido. Tente de novo.");
  }
}
```

```ts
"use server";

import { createOrder, formatOrderNumber, quoteOrder, type OrderQuote } from "@/modules/orders";
import { buildOrderMessage, waMeLink } from "@/modules/whatsapp";
import { getEnv } from "@/shared/env";
import { isDomainError } from "@/shared/errors";
import { toCheckoutError, type CheckoutError } from "./messages";

export type QuoteResult = { ok: true; quote: OrderQuote } | { ok: false; error: CheckoutError };
export type PlaceResult =
  | { ok: true; placed: { numberLabel: string; trackingPath: string; whatsappUrl: string } }
  | { ok: false; error: CheckoutError };

const BOT_ERROR: CheckoutError = { code: "VALIDATION", message: "Não foi possível processar o pedido.", fieldErrors: {} };

function filledHoneypot(payload: unknown): boolean {
  if (typeof payload !== "object" || payload === null) return false;
  const value = (payload as { website?: unknown }).website;
  return typeof value === "string" && value.trim() !== "";
}

export async function quoteOrderAction(slug: string, payload: unknown): Promise<QuoteResult> {
  if (filledHoneypot(payload)) return { ok: false, error: BOT_ERROR };
  try {
    return { ok: true, quote: await quoteOrder(slug, payload) };
  } catch (error) {
    if (isDomainError(error)) return { ok: false, error: toCheckoutError(error) };
    throw error;
  }
}

export async function placeOrderAction(slug: string, payload: unknown): Promise<PlaceResult> {
  if (filledHoneypot(payload)) return { ok: false, error: BOT_ERROR };
  try {
    const order = await createOrder(slug, payload, "web");
    const trackingPath = `/${order.store.slug}/pedido/${order.publicToken}`;
    const trackingUrl = new URL(trackingPath, getEnv().BETTER_AUTH_URL).toString();
    return {
      ok: true,
      placed: {
        numberLabel: formatOrderNumber(order.number),
        trackingPath,
        whatsappUrl: waMeLink(order.store.whatsappPhone, buildOrderMessage(order, trackingUrl)),
      },
    };
  } catch (error) {
    if (isDomainError(error)) return { ok: false, error: toCheckoutError(error) };
    throw error;
  }
}
```

```tsx
import { useRouter } from "next/navigation";
import { useEffect } from "react";

export function AutoRefresh({ intervalMs }: { intervalMs: number }) {
  const router = useRouter();
  useEffect(() => {
    const timer = window.setInterval(() => router.refresh(), intervalMs);
    return () => window.clearInterval(timer);
  }, [router, intervalMs]);
  return null;
}
```

```tsx
import Link from "next/link";
import { notFound } from "next/navigation";
import { connection } from "next/server";
import { Suspense } from "react";
import { FULFILLMENT_LABELS, formatOrderNumber, getOrderTracking, PAYMENT_LABELS, statusLabel } from "@/modules/orders";
import { buildContactMessage, waMeLink } from "@/modules/whatsapp";
import { getEnv } from "@/shared/env";
import { formatBRL } from "@/shared/money";
import { AutoRefresh } from "./_components/auto-refresh";

const FINAL_STATUSES = new Set(["completed", "cancelled"]);

async function Tracking({ params }: { params: Promise<{ slug: string; token: string }> }) {
  const { slug, token } = await params;
  await connection();
  const order = await getOrderTracking(token);
  if (!order || order.store.slug !== slug) notFound();

  const path = `/${slug}/pedido/${token}`;
  const contactUrl = waMeLink(order.store.whatsappPhone, buildContactMessage(order.number, new URL(path, getEnv().BETTER_AUTH_URL).toString()));
  const createdAt = new Intl.DateTimeFormat("pt-BR", { timeZone: order.store.timezone, dateStyle: "short", timeStyle: "short" }).format(
    new Date(order.createdAt),
  );

  return (
    <main className="mx-auto flex w-full max-w-xl flex-col gap-5 px-4 py-6">
      <title>{`Pedido ${formatOrderNumber(order.number)} | ${order.store.name}`}</title>
      {!FINAL_STATUSES.has(order.status) && <AutoRefresh intervalMs={10_000} />}
      <p className="text-sm text-neutral-700 dark:text-neutral-300">{order.store.name}</p>
      <h1 className="text-2xl font-semibold">Pedido {formatOrderNumber(order.number)}</h1>
      <p>Olá, {order.customerFirstName}!</p>
      <p data-testid="order-status" className="rounded-lg bg-neutral-100 p-3 text-lg font-semibold dark:bg-neutral-800">
        {statusLabel(order.status, order.fulfillment)}
      </p>
      <p className="text-sm text-neutral-700 dark:text-neutral-300">
        {FULFILLMENT_LABELS[order.fulfillment]} · feito em {createdAt}
      </p>

      <ul className="flex flex-col divide-y divide-neutral-200 dark:divide-neutral-800">
        {order.items.map((item, index) => (
          <li key={index} className="flex flex-col py-2">
            <div className="flex justify-between gap-3">
              <span>
                {item.quantity}x {item.description}
              </span>
              <span>{formatBRL(item.totalCents)}</span>
            </div>
            {item.options.map((option) => (
              <span key={option} className="text-sm text-neutral-700 dark:text-neutral-300">
                + {option}
              </span>
            ))}
          </li>
        ))}
      </ul>

      <dl className="grid grid-cols-2 gap-1">
        <dt>Subtotal</dt>
        <dd className="text-right">{formatBRL(order.subtotalCents)}</dd>
        <dt>Entrega</dt>
        <dd className="text-right">{formatBRL(order.deliveryFeeCents)}</dd>
        <dt className="font-semibold">Total</dt>
        <dd className="text-right font-semibold">{formatBRL(order.totalCents)}</dd>
        <dt>Pagamento</dt>
        <dd className="text-right">{PAYMENT_LABELS[order.paymentMethod]}</dd>
      </dl>

      <a href={contactUrl} target="_blank" rel="noreferrer" className="rounded bg-green-700 px-4 py-3 text-center font-semibold text-white">
        Falar com a loja no WhatsApp
      </a>
      <Link href={`/${slug}`} className="text-center underline">
        Voltar ao cardápio
      </Link>
    </main>
  );
}

export default function OrderPage({ params }: PageProps<"/[slug]/pedido/[token]">) {
  return (
    <Suspense fallback={<p className="p-6">Carregando pedido...</p>}>
      <Tracking params={params} />
    </Suspense>
  );
}
```
