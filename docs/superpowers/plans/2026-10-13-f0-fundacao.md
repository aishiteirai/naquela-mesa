> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deixar o projeto Naquela Mesa pronto para receber funcionalidades: app Next.js rodando, testes unitários/integração/E2E funcionando, lint de fronteiras de módulo, Postgres + Drizzle, login com Better Auth e um painel `/admin` protegido para o super-admin, tudo verificado em CI.

**Architecture:** Monólito modular em Next.js (App Router). Código de domínio em `src/modules/<nome>/` exposto apenas por `index.ts` (e `client.ts` para código de navegador); utilidades em `src/shared/`; rotas finas em `src/app/`. Fronteiras garantidas por `no-restricted-imports` do ESLint. Banco acessado via Drizzle (query builder, sem relational queries) sobre `pg`.

**Tech Stack:** Node ≥ 24, npm, Next.js 16.4, React 19, TypeScript 5.9, Tailwind 4, Drizzle ORM 0.45 + drizzle-kit 0.31, pg 8, Better Auth 1.7 (plugin `admin`), Zod 4, Vitest 5, Testcontainers (Postgres), Playwright 1.64, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-13-naquela-mesa-mvp-design.md` (esta fase = seção 12, F0)

## Global Constraints

- Dinheiro sempre inteiro em centavos (`*_cents`, tipo `Cents`); nunca float.
- Timestamps no banco em UTC.
- Textos de interface em português do Brasil.
- `src/app/` nunca acessa o banco diretamente; só chama módulos.
- Módulos importados apenas por `@/modules/<nome>` ou `@/modules/<nome>/client`. Dentro de um módulo, apenas imports `./`. Imports `../` proibidos em `src/`. Módulos mantêm estrutura plana (sem subpastas).
- `src/shared/` não importa `@/modules/*` nem `@/app/*`; `src/modules/` não importa `@/app/*`.
- Código de navegador nunca importa `@/modules/<nome>` (index), só `@/modules/<nome>/client`.
- Cadastro público desabilitado; usuários são criados pelo servidor.
- Postgres 17 (`postgres:17-alpine`) em dev, testes e CI.
- Variáveis de ambiente: `DATABASE_URL`, `BETTER_AUTH_SECRET` (≥ 32 caracteres), `BETTER_AUTH_URL`.
- Fim de linha LF em todos os arquivos (`.gitattributes`).
- Trabalhar no branch `f0-fundacao`; abrir PR para `main` ao final.

## Review Focus

1. Variável de ambiente ausente ou inválida → erro na inicialização que nomeia a variável (não um erro genérico do `pg` mais tarde). Teste: Task 3, `env.test.ts`.
2. Login com senha errada ou email inexistente → mesma mensagem genérica "Email ou senha inválidos.", sem revelar se o email existe. Testes: Task 4 (integração, senha errada e email inexistente) e Task 5 (E2E).
3. Visitante sem sessão abrindo `/admin` → redirecionado para `/login`, não erro 500. Teste: Task 5 (E2E).
4. Email com maiúsculas/espaços no `ensureSuperAdmin` → normalizado; rodar duas vezes não duplica usuário. Teste: Task 4.
5. Import profundo entre módulos, inclusive aninhado (`@/modules/a/b/c`) ou via `../` → lint falha. Teste: Task 2.

```ts
export const DOMAIN_ERROR_CODES = [
  "UNAUTHENTICATED",
  "FORBIDDEN",
  "NOT_FOUND",
  "VALIDATION",
  "STORE_CLOSED",
  "ITEM_UNAVAILABLE",
  "PRICE_CHANGED",
  "BELOW_MIN_ORDER",
  "ZONE_NOT_SERVED",
  "INVALID_OPTIONS",
  "FULFILLMENT_DISABLED",
  "PAYMENT_DISABLED",
  "INVALID_TRANSITION",
  "RATE_LIMITED",
] as const;

export type DomainErrorCode = (typeof DOMAIN_ERROR_CODES)[number];

export class DomainError extends Error {
  readonly code: DomainErrorCode;
  readonly details: Record<string, unknown>;

  constructor(code: DomainErrorCode, details: Record<string, unknown> = {}, message?: string) {
    super(message ?? code);
    this.name = "DomainError";
    this.code = code;
    this.details = details;
  }
}

export function isDomainError(error: unknown): error is DomainError {
  return error instanceof DomainError;
}
```

- [ ] **Step 4: Implementar `src/shared/env.ts`**

```ts
import { z } from "zod";

const envSchema = z.object({
  DATABASE_URL: z.url(),
  BETTER_AUTH_SECRET: z.string().min(32, "precisa ter ao menos 32 caracteres"),
  BETTER_AUTH_URL: z.url(),
});

export type Env = z.infer<typeof envSchema>;

export function parseEnv(raw: Record<string, string | undefined>): Env {
  const result = envSchema.safeParse(raw);
  if (!result.success) {
    const issues = result.error.issues.map((issue) => `${issue.path.join(".")}: ${issue.message}`).join("; ");
    throw new Error(`Variáveis de ambiente inválidas: ${issues}`);
  }
  return result.data;
}

let cached: Env | undefined;

export function getEnv(): Env {
  cached ??= parseEnv(process.env);
  return cached;
}
```

- [ ] **Step 9: Implementar `users.ts`**

```ts
import { eq } from "drizzle-orm";
import { db } from "@/shared/db/client";
import { auth } from "./auth";
import { SUPER_ADMIN_ROLE } from "./roles";
import { user } from "./schema";

export type EnsureSuperAdminInput = { email: string; password: string; name: string };

export async function ensureSuperAdmin(input: EnsureSuperAdminInput): Promise<{ id: string; created: boolean }> {
  const email = input.email.trim().toLowerCase();

  const [existing] = await db.select({ id: user.id }).from(user).where(eq(user.email, email)).limit(1);
  if (existing) {
    await db.update(user).set({ role: SUPER_ADMIN_ROLE, updatedAt: new Date() }).where(eq(user.id, existing.id));
    return { id: existing.id, created: false };
  }

  const created = await auth.api.createUser({
    body: { email, password: input.password, name: input.name },
  });
  await db.update(user).set({ role: SUPER_ADMIN_ROLE }).where(eq(user.id, created.user.id));
  return { id: created.user.id, created: true };
}
```

```ts
import { headers } from "next/headers";
import { redirect } from "next/navigation";
import { auth } from "./auth";
import { isSuperAdmin } from "./roles";

export type SessionUser = { id: string; email: string; name: string; role: string | null };

export async function getCurrentUser(): Promise<SessionUser | null> {
  const session = await auth.api.getSession({ headers: await headers() });
  if (!session) return null;
  const { id, email, name, role } = session.user;
  return { id, email, name, role: role ?? null };
}

export async function requireUser(): Promise<SessionUser> {
  const user = await getCurrentUser();
  if (!user) redirect("/login");
  return user;
}

export async function requireSuperAdmin(): Promise<SessionUser> {
  const user = await requireUser();
  if (!isSuperAdmin(user)) redirect("/");
  return user;
}
```

```tsx
"use client";

import { useRouter } from "next/navigation";
import { type FormEvent, useState } from "react";
import { authClient } from "@/modules/auth/client";

export function LoginForm() {
  const router = useRouter();
  const [error, setError] = useState<string | null>(null);
  const [pending, setPending] = useState(false);

  async function onSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setPending(true);
    setError(null);
    const form = new FormData(event.currentTarget);
    const { error: signInError } = await authClient.signIn.email({
      email: String(form.get("email")),
      password: String(form.get("password")),
    });
    setPending(false);
    if (signInError) {
      setError(
        signInError.status === 429 ? "Muitas tentativas. Tente novamente em instantes." : "Email ou senha inválidos.",
      );
      return;
    }
    router.push("/admin");
    router.refresh();
  }

  return (
    <form onSubmit={onSubmit} className="flex flex-col gap-4">
      <label className="flex flex-col gap-1 text-sm">
        Email
        <input name="email" type="email" required autoComplete="email" className="rounded border px-3 py-2" />
      </label>
      <label className="flex flex-col gap-1 text-sm">
        Senha
        <input
          name="password"
          type="password"
          required
          autoComplete="current-password"
          className="rounded border px-3 py-2"
        />
      </label>
      {error && (
        <p role="alert" className="text-sm text-red-600">
          {error}
        </p>
      )}
      <button type="submit" disabled={pending} className="rounded bg-neutral-900 px-4 py-2 text-white disabled:opacity-50">
        {pending ? "Entrando..." : "Entrar"}

}
```

```ts
const ADMIN_PASSWORD = process.env.E2E_ADMIN_PASSWORD ?? "e2e-senha-123";

test("visitante sem sessão é redirecionado de /admin para /login", async ({ page }) => {
  await page.goto("/admin");
  await expect(page).toHaveURL(/\/login$/);
  await expect(page.getByRole("heading", { name: "Entrar" })).toBeVisible();
});

test("senha errada mostra erro genérico", async ({ page }) => {
  await page.goto("/login");
  await page.getByLabel("Email").fill(ADMIN_EMAIL);
  await page.getByLabel("Senha").fill("senha-errada-999");
  await page.getByRole("button", { name: "Entrar" }).click();
  await expect(page.getByRole("alert")).toHaveText("Email ou senha inválidos.");
});

test("email inexistente mostra o mesmo erro genérico", async ({ page }) => {
  await page.goto("/login");
  await page.getByLabel("Email").fill("ninguem@naquelamesa.test");
  await page.getByLabel("Senha").fill(ADMIN_PASSWORD);
  await page.getByRole("button", { name: "Entrar" }).click();
  await expect(page.getByRole("alert")).toHaveText("Email ou senha inválidos.");
});

test("super-admin entra no painel e sai", async ({ page }) => {
  await page.goto("/login");
  await page.getByLabel("Email").fill(ADMIN_EMAIL);
  await page.getByLabel("Senha").fill(ADMIN_PASSWORD);
  await page.getByRole("button", { name: "Entrar" }).click();

  await expect(page).toHaveURL(/\/admin$/);
  await expect(page.getByRole("heading", { name: "Painel do super-admin" })).toBeVisible();

  await page.getByRole("button", { name: "Sair" }).click();
  await expect(page).toHaveURL(/\/login$/);

  await page.goto("/admin");
  await expect(page).toHaveURL(/\/login$/);
});
```

````markdown
# Naquela Mesa

Cardápio digital e pedidos para restaurantes da região.

- Spec do MVP: `docs/superpowers/specs/2026-10-13-naquela-mesa-mvp-design.md`
- Planos: `docs/superpowers/plans/`

## Requisitos

- Node 24+ (`.nvmrc`)
- Docker (Postgres local e testes de integração)

## Primeiros passos

```bash
npm install
cp .env.example .env.local        # gere BETTER_AUTH_SECRET com: openssl rand -base64 32
npm run db:up
npm run db:migrate
npm run admin:ensure -- voce@exemplo.com uma-senha-forte "Seu Nome"
npm run dev
```

Acesse http://localhost:3000/login.

## Scripts

| Script | O que faz |
|---|---|
| `npm run dev` | servidor de desenvolvimento |
| `npm run lint` | ESLint (inclui fronteiras de módulo) |
| `npm run typecheck` | checagem de tipos |
| `npm test` | testes unitários |
| `npm run test:int` | testes de integração (Postgres via Docker) |
| `npm run test:e2e` | testes E2E (Playwright; requer banco migrado e super-admin `e2e-admin@naquelamesa.test`) |
| `npm run db:generate` | gera migration a partir dos schemas |
| `npm run db:migrate` | aplica migrations |
| `npm run admin:ensure -- <email> <senha> [nome]` | cria ou promove super-admin |

## Arquitetura

Monólito modular. Código de domínio em `src/modules/<nome>/`, exposto só por `index.ts`
(servidor) e `client.ts` (navegador). Utilidades em `src/shared/`. Rotas finas em `src/app/`.
Imports `../` são proibidos; o lint falha se um módulo importar internals de outro.
````
